# G9 结果概览与现场回归准备：设计与验收记录

日期：2026-10-04  
范围：只简化回测结果和记录页的呈现，不修改回测算法、历史数据、已有 run、真实连接、CTP 或实盘提醒。

## 设计

1. 结果区首个页签改为“回测概览”，优先显示合约、周期、区间、策略、净收益、收益率、期末权益、最大回撤、成交数、已平仓数、胜率、手续费和当前持仓。
2. 概览提供四个明确下一步：修改策略、重新选择数据、按当前配置再次回测、导出结果。它们复用现有工作流，不覆盖旧 run。
3. 结果页签统一为：回测概览、成交流水、已平仓交易、策略信号、数据质量、高级诊断 / 运行日志；每页保留一句用途说明。
4. 记录页默认显示当前 run 和常用导出；手填 run ID、原始文件读取和筛选下沉到“高级设置”。
5. 桌面入口统一为“期货研究与回测工作台”，继续打开当前白糖示例；旧诊断入口保留“勿用于回测”标识。

## 验收标准

- [x] 完成/打开 run 后自动回到“回测概览”。
- [x] 概览显示交易与信号两类结果所需字段，信号策略的收益字段明确显示“不适用”。
- [x] 四个下一步按钮能返回策略/数据、复用当前配置回测和导出结果。
- [x] 详细表格、数据质量、运行日志和原始文件入口仍可访问。
- [x] 构建无新增警告/错误；发布包清单和哈希校验通过；白糖数据与历史 run 未变化。
- [x] 桌面入口名称已收口；目标程序启动并保持响应。

## 实施结果

- 结果首屏改为“回测概览”，交易 run 展示合约/周期/区间/策略、净收益、收益率、期末权益、最大回撤、成交数、已平仓数、胜率、手续费和当前持仓；信号 run 的收益类字段显示“不适用”。
- 概览按钮已接入现有策略页、数据页、统一回测入口和导出逻辑；历史 run 仍只读，重新回测前会退出只读上下文。
- 记录页保留当前 run 和常用导出，原始文件、手填 run ID 和筛选下沉到高级设置；结果页签保留成交流水、已平仓交易、策略信号、数据质量和高级诊断/运行日志。
- 桌面正式入口已从“白糖SR2701回测工作台.lnk”更名为“期货研究与回测工作台.lnk”，目标仍为当前白糖示例包；旧诊断入口未作为正式入口使用。
- Release 构建通过：0 个警告、0 个错误；发布包清单校验：10021 个文件，0 个缺失或哈希失败；应用包启动后进程保持 `Responding=True`。
- 当前环境的 Windows UI 自动化没有暴露可绑定的目标窗口句柄，因此未把截图级视觉和人工点击验收宣称为已完成；仍需用户打开桌面入口人工确认概览布局和四个按钮的实际点击效果。
