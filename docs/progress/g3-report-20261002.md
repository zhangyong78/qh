# G3 交易回放实现报告

日期：2026-10-02，Asia/Shanghai  
状态：核心实现与离线夹具验证完成，提交负责人审核；不进入 G4/G5。

## 1. 本轮实现

- `worker/qh_signal_worker.py` 接受 `kind=signal|trade`。交易策略在完成 K 线上输出可选信号和独立交易意图；G2 信号回放忽略交易意图，原有信号路径继续可用。
- `src/Qh.Core/TradeReplayRunner.cs` 实现完成线信号、下一根有效 K 线开盘一次性撮合、开多/平多/开空/平空、反向先平后开、固定或比例手续费、不利滑点、保证金门禁、资金不足不重试、浮盈亏、权益曲线、最大回撤、止损止盈下一根开盘执行、取消与严格质量门禁。
- `src/Qh.Core/TradeRunStore.cs` 保存独立 `trade-runs/<run-id>`，包括策略副本、`run.json`、质量、signals/intents/orders/fills/closed-trades/positions/equity/risk-events/unfilled JSONL、Worker 日志；成交可导出 CSV。
- WPF 增加 G3 交易配置 JSON、交易回放/取消、权益曲线摘要、成交只读表和交易 run 只读重开入口。没有接入 TqSdk、CTP、真实下单或通知。
