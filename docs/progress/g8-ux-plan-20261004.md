# G8 策略页与统一回测入口：设计与验收记录

日期：2026-10-04  
范围：只调整本地研究工作台的策略选择、参数填写和回测入口，不改变历史数据、已有 run、交易撮合规则或真实连接链路。

## 目标

让用户从“选择策略 → 填参数 → 开始回测”完成主要操作，同时保留原有 Python 路径、原始 JSON、严格/探索模式、配置检查、取消和历史 run 能力。

## 页面设计

策略页的默认路径分为三层：

1. **策略卡片**：内置 `sma_ema_cross.py`、`sma_ema_cross_trade.py`、`period_signal.py` 三个候选，显示中文名称、策略类型、warmup、适用周期和默认参数提示。
2. **参数表单**：根据已加载策略的 descriptor 动态生成参数控件。数值参数使用文本框，有限 choices 使用下拉框；表单修改会同步到兼容的参数 JSON。
3. **高级设置**：保留 Python 文件路径、原始参数 JSON、探索模式、配置检查，以及信号/交易分别回放按钮，便于复现旧流程和排查问题。

## 统一入口语义

“开始回测”根据策略 descriptor 的 `kind` 自动路由：

- `signal`：执行严格信号回放，只产生策略信号，不产生订单、成交和收益。
- `trade`：执行本地交易回放，按已有 TradingConfig 模拟成交、手续费、滑点、权益和报告，不连接实盘、不下真实单。

数据快照、起止时间和质量门禁仍由原有回放核心校验；取消、检查配置、打开历史 run 和导出能力继续保留。
