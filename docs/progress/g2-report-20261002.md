## 范围与明确未做事项

本轮只实现离线研究信号回放：本地 Python 策略描述/参数校验、逐根完成 K 线回放、指标计算、质量门禁、独立运行记录和只读查看/筛选/导出。未接入 TqSdk、CTP、真实通知、交易、PnL、手续费或实盘链路；未修改 `docs/04-负责人监督记录.md`。

## 实现内容

- `docs/progress/g2-contract.md`：固定 CSV 起始时间、K 线结束时间、`[startInclusive,endExclusive)`、预热、指标公式和策略接口。
- `strategies/sma_ema_cross.py`：首个均线交叉示例，支持 SMA/EMA、fast/slow 参数和版本元数据。
- `worker/qh_signal_worker.py`：逐根 JSON 命令协议；策略只收到当前完成 K 线、已到达数据的指标方法和正式标记；重复 `bar_end` 不再次执行；支持 `cancel`、超时、运行异常、未完成 K 线和退出错误。
- `src/Qh.Core/StrategyCatalog.cs`：策略语法/元数据描述、参数定义和 SHA-256。
- `src/Qh.Core/SignalReplayRunner.cs`：质量门禁、预热/正式边界、Worker 生命周期、进度、取消和错误状态。
- `src/Qh.Core/SignalRunStore.cs`、`SignalModels.cs`：独立 run ID、策略副本、`run.json`、质量副本、Worker 日志、单行 `signals.jsonl`、只读筛选和 CSV 导出。
- `src/Qh.Cli/Program.cs`：`describe`、`replay`、`read-run`、`export-signals`，保留 G1 的导入/质量/指标命令。
- `src/QhApp/`：增加本地策略选择、严格回放、取消、只读信号区和导出按钮；WPF 编译通过，但本轮没有原生窗口人工点击验证。
