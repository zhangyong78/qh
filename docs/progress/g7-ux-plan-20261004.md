# G7 简化研究工作台 UX 方案（2026-10-04）

## 目标

在不改变现有数据模型、Python 策略契约、白糖历史数据、回测口径和历史 run 的前提下，把当前工程调试式界面收束为一条可理解的研究流程：

`选择合约 → 选择周期 → 选择行情来源和区间 → 获取/加载行情 → 选择策略 → 设置参数 → 开始回测 → 查看结果`

本阶段只做离线研究与 TqSdk 历史数据入口，不接入 CTP、真实下单或实盘提醒。

## 界面结构

### 顶部：当前步骤提示

主窗口顶部增加 8 步状态条，显示当前步骤、下一步和当前数据状态。步骤由已有数据/策略/run 状态驱动，不新增一套状态机。

### 数据页：历史数据作为主入口

- 默认先显示“天勤历史数据”卡片：具体合约、固定周期选项、日期区间、检查覆盖、下载并发布。
- 周期给用户显示“1分钟、5分钟、15分钟、30分钟、60分钟、日线”，内部仍使用秒数。
- 具体合约提供白糖、铜、螺纹钢示例和格式提示；仍拒绝主连、指数、888/999。
- CSV/本地快照保留为“本地文件 / 高级”区域，供离线数据和故障排查使用。

### 策略页：默认表单，高级项折叠

- 保留现有策略文件选择、加载校验和 Python 策略兼容。
- 默认先展示策略路径、类型/说明、参数 JSON、回放区间和开始回测入口。
- warmup、严格/探索模式和原始 JSON 细节用说明文字/高级区域表达，不删除原能力。

### 结果页：先看结论，再看明细

- 先展示摘要、权益曲线和K线/信号/成交。
- 成交流水、已平仓交易、策略信号、数据质量和运行日志继续保留为页签。
- 每个页签增加一句用途说明；历史 run、筛选和导出保持只读语义。

### 连接页：明确边界

明确写出：离线回测不需要账号；只有下载天勤历史数据或实时验证才需要 TqSdk 账号密码；测试连接不下单；密码只在本机输入。实时会话、Worker 和原始日志留在高级/运行状态区域。

## 验收边界

- 不修改 `artifacts/sr2701-15m` 的数据、snapshot、run 或回测结果。
- 不删除 CSV、快照、历史 run、Python 策略和交易回放能力。

- 构建必须无错误；现有回测入口仍能打开白糖 SR2701 结果。
