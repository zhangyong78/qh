# 期货研究与回测工作台使用说明

## 先看结论

当前版本是 Windows 本地离线研究候选，适合导入历史行情、运行本地 Python 策略和查看回测报告。交易回放只在本地模拟成交、手续费、滑点、保证金和权益变化，不连接真实下单链路。

白糖、铜、螺纹钢等都是同一套通用工作台中的不同合约实例，不对应不同界面。切换品种时只需要更换行情数据中的合约字段（例如 `CZCE.SR701`）、周期、交易日区间和策略参数；数据、策略、信号、交易回放、图表和报告页面共用同一套功能。旧诊断程序文件仍保留，但桌面不再提供入口；需要时由开发/诊断流程启动，不用于历史回测。

桌面已有“期货研究与回测工作台”快捷方式；它仍默认打开白糖 SR2701 示例。旧诊断程序文件仍保留，但桌面不再提供入口；需要时由开发/诊断流程启动。也可以在 PowerShell 运行：

```powershell
& 'D:\mycode\qh\tools\open-sr2701-backtest.ps1'
```

## 推荐操作流程

主界面顶部会显示当前步骤和下一步。最短路径是：数据页选择已有数据 → 策略页加载策略 → 开始回测 → 查看结果。白糖、铜、螺纹钢等合约共用这套工作台，只切换合约和数据，不切换界面。

### 1. 启动并准备数据

打开“数据”页：

1. 数据页第一块“选择已下载/已导入的数据”会直接列出快照，条目显示合约、中文周期、日期范围和根数；选择后点击“加载所选数据”。15/30/60 分钟数据在这里可以直观区分。
2. 没有现成快照时，点击“导入本地 CSV”导入行情。导入会进行排序、重复、缺失值、OHLC、时间连续性和完成状态检查，并生成本地快照。
3. 只做历史回放时，不需要连接账号。
4. 需要供应商历史数据时，在“连接”页先测试账号，再回到“数据”页的“下载新历史数据”。“具体合约（点击选择）”先列出当前数据根已发布的全部具体合约，例如“白糖 · 郑商所 · CZCE.SR701 · 本地已验证，可直接使用”；下方少量常用入口只显示品种前缀，并明确标为“需完整月份、需连接+日历、本地无数据”，不是行情覆盖承诺，选中后仍要展开“手动输入其他具体合约（高级）”补完整代码。周期下拉框显示 1分钟、5分钟、15分钟、30分钟、60分钟、日线。主连、指数、888/999 不会列入有效具体合约。下拉选择会清空旧的手动输入；手动输入后则明确进入手动模式，不会被隐藏的旧下拉值覆盖。
5. 下载日期使用 Windows 日期控件：左侧为开始日期，右侧为结束日期，均按北京时间处理，结束日期当天完整包含。通常不需要填写 ISO 字符串；只有需要精确到时分秒时，才展开“高级：精确时间（可选，ISO 8601）”。
6. 下载前先看“历史下载前置检查”。日历按 `QH_TQSDK_CALENDAR_PATH`、包目录 `calendar.json`、当前数据根 `calendar.json` 的顺序寻找；日线选择日期不会自动下载。若当前数据根已有目标具体合约的已验证 15 分钟快照，可点击“从当前已验证快照生成本机研究日历”，程序会保存 `calendar.json` 和 `calendar-generation-audit.json`，只使用快照真实交易日/实际时段，不猜节假日，也不冒充供应商官方日历。生成后仍要明确点击“检查覆盖”，确认后再点击“下载并发布”。若日历缺失或不适用，程序不会发起供应商请求。

### 2. 选择和校验策略

打开“策略”页：

1. 策略页顶部先确认“当前数据”显示的是目标合约、周期、覆盖区间和根数。若同一合约已有多个周期，可直接在“直接切换周期（当前合约）”下拉框选择 15/30/60 分钟，程序会自动加载该周期的最新快照；需要下载新周期时再点击“去数据页切换合约/周期”。内置候选会明确显示信号或交易类型；白糖 EMA 动态限价多头实验可选 `EMA 动态委托做多（QQOKX）`，加载后会显示 EMA/ATR、最小变动价位和手续费偏移参数，再通过交易回测结果页查看成交、净收益和回撤。
2. 点击“加载并校验所选策略”。加载后会按 descriptor 生成参数表单；数值直接填写，有限选项从下拉框选择。策略必须提供 `STRATEGY`、`create_strategy(parameters)` 和 `on_bar(context)`。
3. 快线/慢线参数的单位是 K 线根数，不是分钟。例如同样 20 根，15 分钟数据约覆盖 5 小时，60 分钟数据约覆盖 20 小时。需要精细控制时，再在“高级设置”中填写 Python 路径或原始参数 JSON。原始 JSON 仍兼容旧策略参数格式，例如：

```json
{"fast_period":20,"slow_period":60}
```

4. 回测起点和终点会在加载数据/策略后自动填充。必要时再修改；区间是左闭右开：包含起点，不包含终点。
5. 正式研究保持“探索模式”不勾选。探索模式允许带质量缺口的数据继续运行，只适合排查数据，不适合作为正式结果。
6. 点击“检查回放配置”，确认快照、策略、参数、区间、warmup 和正式覆盖范围都通过。
7. 点击主按钮。信号策略按钮会显示“开始信号回放（无盈亏）”；交易策略按钮会显示“开始模拟交易回测（有盈亏）”。程序会按策略类型自动选择对应回放：信号策略不产生成交；交易策略只做本地模拟，不会向期货账户下单。

### 3. 运行信号回放

“开始回测”对信号策略会执行严格信号回放，也可以在高级设置中点击“开始信号回放（严格）”分别执行。信号回放只计算策略信号，不生成订单、成交、手续费或收益。完成后可在右侧“策略信号”页查看信号，也可在“记录”页导出当前信号 CSV。

信号回放中可以点击“取消信号回放”。取消后的适用 partial 记录会保留，状态不会伪装成成功完成。

### 4. 运行交易回放

在“交易回放”区域检查交易配置 JSON，或使用高级设置中的简化交易参数表，再点击“开始交易回放”。配置通常包括初始资金、手数、合约乘数、最小变动价位、手续费、滑点和保证金率。 

交易回放会把策略信号转换成 intent，并按下一根有效K线开盘价模拟成交，然后生成订单、成交、持仓、权益、已平仓交易和风险记录。它不会向期货账户发送真实订单。

“复制当前交易配置到新 run”会创建新的研究上下文，原 run 保持只读不变；“取消交易回放”会停止任务并保留已写入的适用记录。

### 5. 查看图表和报告

右侧区域提供：

- K线图：可用“最近240根/全量”、加减号、滚轮和拖动查看；策略均线、信号和成交标记会叠加显示。
- 回测报告：查看区间、策略、参数、成交数、净收益、期末权益、胜率和最大回撤。
- 成交流水：查看每笔成交的动作、方向、手数、成交价、手续费和滑点。
- 已平仓交易：查看入场、离场、毛利、费用和净利。
- 策略信号：查看K线时间、类别、方向、参考价格和说明。
- 数据质量：查看快照质量、缺口、重复和覆盖信息。
- 运行日志：查看本次任务状态和 Worker 诊断。

### 6. 打开历史结果和导出

在“记录”页输入已有 run ID，点击“打开已有 run”。历史 run 以只读方式恢复，不会重新计算原结果。

可以按类别、方向和时间范围应用只读筛选；筛选只改变当前显示，不修改 run 文件。交易结果可以导出成交 CSV、权益 CSV 和交易摘要 JSON；信号结果可以导出当前信号 CSV。下拉框还可以读取 `run.json`、`quality.json`、`assumptions.json`、`orders.jsonl`、`positions.jsonl`、`risk-events.jsonl` 和 `worker.log` 的前200行。

### 7. 结果概览和高级诊断

回测完成或打开历史 run 后，右侧默认进入“回测概览”，先显示合约、周期、区间、策略和核心收益/风险指标。信号策略不产生收益、成交和持仓，因此这些字段会显示“不适用”。

概览中的“修改策略”“重新选择数据”“按当前配置再次回测”“导出结果”只复用当前工作流；历史 run 仍是只读，不会被覆盖。

结果页签依次为“回测概览”“成交流水”“已平仓交易”“策略信号”“数据质量”和“高级诊断 / 运行日志”。“记录”页默认展示当前 run 和常用导出；手填 run ID、读取原始文件和信号筛选位于“高级设置”。

## 连接、实时会话和 Worker

“连接”页不是离线回放的必需项：

- 账号、密码：只在本机输入。不要把密码发送到聊天；保存选项使用当前 Windows 用户保护存储。
- “测试连接”：只验证 TqSdk 依赖、握手和权限，不启动策略、不下单。
- “删除本机凭据”：只删除当前 Windows 用户保护存储里的凭据，不删除行情和回测结果。
- “实时行情记录”：用于实时序列验证和记录，当前版本不做真实交易。
- “后台 Worker”：本地受管理的 Python 子进程。回放通常会自动管理它；“取消 Worker 任务”等待取消确认，“停止 Worker”等待正常停止确认。

### 连接页中的 G5-A 本机提醒

“实时提醒（G5-A/G5-B 本机基础）”只消费 LiveSessionCoordinator 已接受的完成 K 线。启动前必须在“策略”页加载并校验策略；实例会固定策略版本、文件哈希、参数摘要和预热需求。完成 K 线由独立策略 Worker 求值后再进入软件内信号账本；预热不写信号，正式信号可通知，启动补缺/恢复期信号只记录、不弹窗、不播声音。

提醒账本位于数据目录的 `live-notify.sqlite`，实例、业务信号和通知尝试均持久化。业务去重键包含实例、策略版本、具体合约、周期、K 线结束时间、类别和方向；重启后重复输入不会重复业务信号。发送前先记录待尝试状态，再调用 Windows 提醒/声音；“已尝试”不代表用户已看到。

常用操作是启动提醒、暂停/恢复通知、静音/开启声音、停止实例和“测试通知”。测试通知明确不会写入真实信号账本；暂停仍继续记录，静音只影响声音，停止或失败实例拒绝继续记账。可设置同一实例、同一类别、同一方向的冷却秒数（默认 0）；反向信号不受抑制，软件内信号仍会保留并显示通知状态。账本最多保留 5 条活跃实例记录，但当前实时桥接入口一次只运行一个会话，不代表支持并发运行 5 个实时会话。

G5-B 合成验证已覆盖：预热无通知、正式完成线产生信号、同一 bar/重启去重、恢复期账本抑制通知，以及策略异常只使当前实例进入“策略故障”。当前实时桥接入口一次只运行一个会话；真实 TqSdk 持续行情、断线现场和完整交易日仍待人工验证。

G5-A 仍不是正式 G5：真实 TqSdk 持续权限、真实行情覆盖、断线现场恢复、Windows 弹窗实际可见性和两个完整交易日仍需人工或真实权限验证；不接 CTP、不下真实单、不发送远程通知。

## 常用术语

- SMA：简单移动平均线，例如 SMA20 是最近20根K线收盘价的算术平均。
- EMA：指数移动平均线，越近的数据权重越高。
- ATR：平均真实波幅，用于估计波动范围，常用于止损或仓位计算。
- warmup：指标预热根数。预热数据用于建立指标，不计入正式信号和正式回测区间。
- signal：策略给出的研究信号，例如上穿、开多或开空意图；信号本身不是成交。
- intent：交易策略提出的开仓、平仓或反向意图；撮合器会检查资金、仓位和下一根有效K线。
- fill：模拟成交记录，包含成交价、数量、手续费和滑点。
- 严格模式：数据存在质量缺口或正式区间覆盖不足时阻止回放，适合正式研究。
- 探索模式：允许带缺口数据继续运行，并在结果中保留不完整标记，只适合排查。
- 左闭右开：`[start, end)`；包含 start，不包含 end。
