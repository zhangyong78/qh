## 第一版定位

个人自用的 Windows 国内期货研究软件。用户编写 Python 策略，在本地历史行情上回放信号、模拟交易并查看结果；接入实时行情后生成本机提醒。

默认以分钟线、日线和单个具体月份期货合约为主。Python 负责策略与研究计算，C# WPF 负责桌面界面。CTP 行情接入作为后续扩展点。本版不发送真实交易委托。

“类似文华”指行情列表、K 线、指标、策略运行和结果查看的操作体验，不代表复制界面或兼容麦语言。
