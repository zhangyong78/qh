# 交互流程与页面状态

版本：v1.0  
日期：2026-10-02  
适用：个人自用 Windows 研究与提醒软件

## 1. 总体窗口与导航

主窗口左侧为总览、数据中心、行情图表、策略管理、历史研究、实时提醒、运行日志、设置。顶部显示当前工作区；底部持续显示行情连接、Python 进程、后台任务和本地数据状态。

信号、数据错误、策略错误使用图标及文本区分，不仅依赖颜色。行情价格红涨绿跌遵循国内习惯；零变化中性。金额显示币种、手数显示“手”，所有日期显示交易日或自然时间标签。

默认不显示“下单”“资金账户”“自动交易”等本版未实现的入口。没有数据或没有账号时显示可执行的下一步，而不是空白窗口。

后台任务共享一个任务抽屉，按下载、导入、回测区分。实时提醒长期运行实例不伪装成可结束进度条。

## 2. 第一次启动

1. 启动软件，进入欢迎引导，显示功能定位“历史研究与本机提醒”。
2. 选择用户数据目录，显示可用磁盘空间和读写检查结果；默认使用用户本地应用数据目录。
3. 显示运行环境检测：Python、.NET、历史数据组件、通知能力。发布包缺失组件时给出明确修复入口；开发环境不自动升级全局环境。
4. 选择“连接 TqSdk”或“先离线研究”。两条路径都能进入主窗口。
5. 连接路径中输入账号和密码。密码遮挡，可选择是否保存，保存时使用 Windows 用户级保护。
6. 点击“测试连接”，按钮进入忙碌状态，可取消；验证账号、连接和能力，不自动批量下载。
7. 成功后显示“实时行情可用/历史下载权限待测或可用”的准确状态。失败区分账号、网络、权限，并保留可编辑表单。
8. 进入总览，显示“尚无历史数据”，提供“下载历史”和“导入 CSV”入口。

返回引导不会重复创建工作区。选择离线不会循环弹出登录窗口。以后通过设置修改账号和目录，切换目录前确认没有占用任务。

## 3. 数据中心：下载历史

1. 进入数据中心，查看按合约/周期排列的数据覆盖表。
2. 点击“下载历史”，打开任务表单。
3. 搜索品种及具体合约，展示交易所、中文名称、代码和有效日期；到期合约是否可下载以服务能力显示。
4. 选择周期：日线、1 分钟。其它分钟周期提供“从本地 1 分钟聚合”说明。
5. 选择日期范围，结束日期不得晚于可获取范围；未收盘交易日明确可能只有部分数据。
6. 点击“检查范围”，展示现有覆盖、缺少区间、账号能力、预计分段数。数据量无法估算时不编造大小或完成时间。
7. 点击“开始下载”，任务进入队列；默认跳过已通过校验的相同版本区间。
8. 页面显示连接、下载、校验、发布各阶段及当前合约。后台允许浏览已有数据。
9. 遇到网络错误，有限次数重试，随后转为“失败，可重试”，显示已完成与剩余区间。
10. 完成后展示实际覆盖及质量摘要，提供“打开图表”和“查看质量报告”。

权限不足时表单显示专业权限要求，提供账号设置和 CSV 导入入口；不自动购买或弹出外部付款流程。空结果显示“没有取得数据”，不会显示成功覆盖。

点击取消后进入“正在取消”，工作进程确认后显示“已取消”。完整已发布区间保留；临时区间标记不可用。再次下载从缺少部分继续。

## 4. 数据中心：导入、校验和整理

1. 点击“导入 CSV”，选择本地文件。
2. 预览前若干行，选择列映射、时区、周期、合约和成交量口径。
3. 说明最少字段：时间、开高低收及必要合约元数据；缺少字段时禁用开始按钮并标出缺项。
4. 点击“预检”，显示无效行、重复、冲突、范围及将使用的交易时段配置。
5. 无冲突时可以正式导入；冲突时用户选择保留现有数据或生成新版本，不默认覆盖。
6. 导入完成查看质量报告；删除或修改源 CSV 不影响已发布数据。
7. 从覆盖表选中 1 分钟数据，点击“生成周期”，选择 5/15/30/60 分钟。
8. 聚合完成展示交易时段边界说明和实际覆盖，保留源数据版本关联。

删除历史数据前显示合约、区间、磁盘大小和引用结果数量。正被任务使用时禁止删除；已有回测引用的快照默认保留。批量清理不是第一版必要功能。

## 5. 行情图表：研究入口

1. 从自选列表或数据中心选择合约，进入行情图表。
2. 顶部选择合约、周期及日期范围；显示当前数据来源、本地覆盖和实时连接状态。
3. 主图显示 K 线，下方显示成交量，可添加均线等首批指标；首批指标清单在实现前冻结，不自行扩大。
4. 鼠标滚轮缩放、拖动平移；十字光标同时显示时间、OHLC、成交量和持仓量。
5. 切换合约/周期后加载状态可见，取消上一查询，防止旧结果覆盖新选择。
6. 查看回测结果时叠加信号和模拟成交，两者使用不同符号，点击弹出来源、时间及说明。
7. 点击“用该数据研究”，打开历史研究页并带入合约、周期、当前范围。

休市空档是否压缩在设置中统一；十字光标始终映射实际时间。实时最新一根标为“未完成”，不与回测触发 K 线混淆。

无覆盖显示下载/导入入口。断线仍允许看本地数据，报价标为过期，不能显示实时绿灯。显示主连时提示其为研究序列，交易回测入口要求选择具体合约。

## 6. 策略管理：添加与修改

1. 点击“添加策略”，选择本地可信 Python 文件。
2. 显示文件路径、策略名称、信号/交易类型、版本及摘要。读取元数据和校验在受管理进程中执行。
3. 校验接口、参数类型、范围和预热要求。语法错误显示文件及行号，运行错误显示技术详情。
4. 成功后策略进入列表，展示可用于信号回放、交易回测或实时提醒的能力。
5. 点击策略可编辑默认参数并保存配置；不修改原 Python 文件。
6. “打开文件位置”或复制路径供外部编辑器使用，不开发内置完整 IDE。
7. 文件发生变化时标记“文件已修改”，用户点击“重新校验”创建新版本。
8. 已运行实例保持原快照。要使用新版本，停止并重新创建运行实例；页面显示哪些实例仍使用旧版。

加载失败不移除已有有效版本。删除策略配置前检查运行引用；已有回测仍保留策略快照。修改默认参数不会追溯改变旧回测或运行实例。

## 7. 历史研究：信号回放

1. 从策略列表或图表进入历史研究。
2. 选择模式“信号回放”。选择策略、合约、周期、正式起止区间及参数。
3. 显示预热所需范围、正式统计范围和数据质量。预热不足时不能无说明启动。
4. 点击“检查配置”，列出可运行/阻止原因；缺口显示具体区间。
5. 默认严格模式；如果切换探索模式，持续显示数据不完整提示并写入结果。
6. 点击“开始回放”，生成运行编号和输入快照。表单被锁定，仍可切到其它页面。
7. 完成后显示信号摘要、信号表和图表；没有信号时显示“本区间未触发信号”，不当作异常。
8. 点击信号表的一行，图表跳到对应 K 线并突出信号说明。
9. 筛选信号类型、方向和时间，导出当前筛选或全部记录为 CSV。
10. 点击“用此配置实时提醒”，带入策略参数、合约及周期，进入实时配置；不自动开始。

信号回放结果不显示交易收益曲线、胜率等不适用指标。历史回放中的信号不触发实时桌面通知。

## 8. 历史研究：模拟交易回测

1. 选择模式“交易回测”，只有声明交易能力的策略可以选中。
2. 选择具体合约、周期、范围和参数。
3. 输入初始资金、手数、保证金率、费用方式、开平/平今费率、滑点；显示合约乘数及最小价位来源。
4. 旁边固定展示撮合规则：完成 K 线触发、下一根有效 K 线开盘尝试、每单尝试一次、近似成交、不模拟真实排队。
5. 检查数据覆盖、预热和费用配置。缺少历史费用时用户提供假设值，结果持续标注。
6. 点击“开始回测”，生成快照及运行编号；显示已处理 K 线数量、阶段和耗时。
7. 可取消。失败跳到运行日志并保留配置，提供修改后重新运行入口；不得直接覆盖旧结果。
8. 完成后默认展示权益曲线和关键指标，下方切换“信号、交易、持仓、未成交、配置、日志”。
9. 点击信号定位信号 K 线；点击成交定位成交 K 线并显示滑点、费用和持仓变化。
10. 期末未平仓单独显示浮盈亏。零交易时胜率等显示“不适用”。
11. 可导出交易/信号 CSV、权益 CSV 和带假设说明的结果摘要；PDF 报告不在第一版。
12. 点击“复制配置”创建新的运行，旧运行只读。

结果页始终能打开输入参数、数据版本、策略快照和已知限制。进行新数据下载或修改策略，不改变当前结果。

## 9. 实时提醒：创建、运行和暂停

1. 进入实时提醒，点击“创建实例”。
2. 选择有效具体合约、周期、策略版本及参数；显示到期信息。
3. 选择渠道：软件内记录始终开启；桌面通知与声音分别选择。
4. 设置同类同方向冷却时间，默认不冷却。显示一次触发的通知预览。
5. 点击“测试通知”，发出标为测试的通知；提示 Windows 通知权限状态。
6. 点击“检查启动条件”，检查账号、订阅、数据预热、合约有效期和并发上限。
7. 点击“启动”，实例先进入预热。显示还缺多少 K 线或等待原因；预热期间不发真实通知。
8. 完成后进入运行，显示最近收到行情、最近完成 K 线、最近计算和最近信号时间。
9. 新完成 K 线满足条件后，信号先进入列表，再尝试系统通知/声音。
10. 点击信号，打开对应图表与说明；通知点击定位应用内信号详情。
11. 点击“静音”，只停止声音；桌面通知和软件内记录继续。
12. 点击“暂停通知”，选择 15/30/60 分钟或直到手动恢复；计算和信号记录继续，期间信号标明被暂停。
13. 点击“停止实例”，停止计算和该实例订阅需求，历史记录保留。共享订阅在没有其它使用者时才解除。

全局静音与全局暂停通知作用在渠道层，并在顶部持续显示。到期自动恢复只适用于定时暂停。停止实例没有自动恢复时限。

## 10. 实时提醒：异常与恢复

1. 行情连接丢失或超过阈值没有更新，实例显示“断线暂停/等待数据”；阈值依据交易时段，不把休市判为断线。
2. 连接恢复后显示“补缺与预热”，记录中间缺口。
3. 历史权限允许时补齐缺口；不允许时暂停，显示所需范围和处理入口。
4. 恢复期计算产生的信号标记为历史信号，仅记录不弹窗。
5. 数据与指标就绪后切回运行；只对后续新完成 K 线正常提醒。
6. 策略异常时仅故障实例停止，其他实例保持工作。页面显示错误并提供日志和重新校验入口。
7. 用户重启软件后恢复配置和提醒账本；实时实例默认处于停止状态，用户选择启动，不无声自动运行旧策略。
8. 合约到期时暂停实例，提示选择新合约。不能自动换月并沿用旧指标状态。

电脑睡眠恢复沿用断线流程。断线期间不能显示“无信号”作为判断结果，只显示“该区间未完成判断”。

## 11. 总览、日志、设置与退出

总览：数据覆盖摘要、最近研究、运行实例及故障、最新信号。每项均可跳转来源页面；没有记录时提供下一步入口。

日志：按任务/实例、级别和时间筛选；用户说明与技术详情分层；可导出脱敏诊断包。大量策略打印有截断和限流提示。

设置：行情账号、数据目录、显示时区说明、通知/声音、日志保留策略、应用版本和诊断。不提供真实交易柜台字段。

退出时：若有下载、回测或实时实例，列出活动内容，让用户选择“取消退出”或“停止任务并退出”。后者等待停止确认并清理子进程；停止失败显示明确状态和结束进程操作。没有活动任务则正常退出。

## 12. 交互验收走查顺序

路径一：无账号启动 → 导入小型 CSV → 看图 → 加载信号策略 → 回放 → 点击信号 → 导出。

路径二：加载交易策略 → 配置费用 → 手算数据回测 → 核对明细 → 复制配置 → 取消重跑。

路径三：有权限账号连接 → 历史下载 → 质量报告 → 完整区间回测 → 离线复跑。

路径四：实时实例 → 通知测试 → 预热 → 新信号 → 重复更新 → 静音 → 暂停通知 → 停止。

路径五：断网 → 连接恢复 → 补缺 → 历史信号不弹窗 → 新信号正常通知 → 重启去重。

路径六：无权限、坏 CSV、策略异常、进程退出、磁盘不足、合约到期、退出清理。每步检查结果、提示和是否可以继续操作。
